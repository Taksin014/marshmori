Mamori อยู่บนขอบจอ
คอยดู AI ช่วยเขียนโค้ดให้คุณ

มาร์ชแมลโลว์ตัวน้อยที่บอกเมื่อ Claude Code, Codex หรือ Antigravity ขออนุมัติ ถามคำถาม ทำงานเสร็จ หรือเจอปัญหา แล้วให้คุณกดตอบได้ตรงนั้นเลย

ติดตั้ง Marshmori
ฟรี · Windows 10 / 11 (64-bit) · ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง
Marshmori ใช้ได้บน Windows เท่านั้น เปิดหน้านี้จากคอมพิวเตอร์ Windows แล้วกด ติดตั้ง Marshmori ได้เลย

ชี้เมาส์ที่ขอบบนจอ แถบจะเด้งออกมาบอกว่า agent ทำอะไรอยู่

ติดตั้งยังไง

  1. 1กดปุ่ม ติดตั้ง Marshmori ด้านบน
  2. 2เปิดไฟล์ Marshmori-Setup.exe ที่ดาวน์โหลดมา (กดที่ไฟล์ในแถบดาวน์โหลดของเบราว์เซอร์ได้เลย)
  3. 3เสร็จแล้ว ไม่ต้องกดอะไรอีก Marshmori ติดตั้งเองแล้วโผล่ขึ้นมาที่ขอบบนของจอ มีไอคอนบนเดสก์ท็อปและใน Start Menu ให้
ถ้ามีหน้าต่างสีน้ำเงิน "Windows ป้องกันพีซีของคุณ"
กด ข้อมูลเพิ่มเติม แล้วกด เรียกใช้ต่อไป — Windows เตือนแบบนี้กับโปรแกรมใหม่ที่ยังไม่ได้เซ็นดิจิทัล ดาวน์โหลดจากหน้านี้หรือ GitHub ของ Marshmori เท่านั้น

อัปเดตเวอร์ชันใหม่ก็ทำแบบเดียวกัน การตั้งค่าเดิมอยู่ครบ

Mamori ช่วยอะไรได้

เห็นว่า agent ทำอะไรอยู่ทั้งใน terminal, VS Code และ Antigravity โดยไม่ต้องสลับหน้าต่าง
กดอนุญาตและตอบคำถามการ์ดขึ้นที่แถบ หรือ Mamori ยืดคอมาถึงข้างเมาส์ กดตอบแล้ว agent ทำต่อทันที
สั่งงานผ่าน Mamoriเลือก agent กับโฟลเดอร์ พิมพ์งาน แล้วให้ทำเบื้องหลัง ไม่ต้องใส่ API key
